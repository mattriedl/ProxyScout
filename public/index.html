User guide

1

Scrape

Go to Scraper, tick the sources you want (or add your own URL), set threads and a per-source limit, then press Start scraper. New proxies are saved to the database as untested.

2

Test

On Checker, pick what to test — untested, failed only, working (re-verify) or everything — and press Start proxy test. With auto-check on, this happens right after scraping.

3

Filter & export

In Proxies, filter by type, anonymity, Google, country and speed, sort any column, select rows, then copy, re-test, export or delete them.

What each test means

Response
Time from opening the connection to the first byte of the target page, through the proxy.
Elite
The judge sees neither your real IP nor any proxy headers.
Anonymous
Your IP is hidden, but headers such as Via or X-Forwarded-For reveal a proxy.
Transparent
Your real IP is passed through to the site.
Google
The proxy loaded google.com over HTTPS without a block or captcha page.
HTTPS
An HTTP proxy that also supports CONNECT tunnelling with valid TLS.

Tips

  • Free lists are mostly dead. 150–300 threads with a 6–8 s timeout is a good balance on a server.
  • Use Failed scope to give dead proxies a second chance later — many come back.
  • For accurate anonymity grading, the judge must reach you directly. ProxyScout's own /judge works when the app is reachable on a public address.
